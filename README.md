# MaterialYou Prefs

A Material Design 3 (Material You) preference list app built with Jetpack Compose.

## Features

- Material 3 (Material You) design with dynamic color support (Android 12+)
- Grouped preference list with icon + title + subtitle per row
- Bottom navigation with Home, Feature, and Settings tabs
- Detail screen for each preference item
- Edge-to-edge UI with Navigation Compose

## Tech Stack

- Kotlin 2.0.20
- Jetpack Compose (BOM 2024.09.02)
- Material 3 / Material You Dynamic Color
- Navigation Compose 2.8.0
- AGP 8.5.2 / Gradle 8.7

## Build

```bash
./gradlew assembleDebug
```

## CI/CD

GitHub Actions automatically builds a debug APK on every push to `main`.
